# AquaFarm — ต้นแบบแดชบอร์ดฟาร์มกุ้ง

เว็บต้นแบบสำหรับติดตามและควบคุมฟาร์มกุ้ง เปิด `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งไลบรารี

## ความสามารถในต้นแบบ

- แสดงค่าออกซิเจนละลายน้ำ pH และอุณหภูมิ พร้อมกราฟข้อมูลจำลอง
- ตั้งเกณฑ์เตือน pH ต่ำ/สูง และทดลองการแจ้งเตือน
- สลับโหมดให้อาหารอัตโนมัติ/ควบคุมเอง
- เปิด/ปิดและปรับความเร็วกังหันตีน้ำ
- เปิด/ปิดและปรับอัตราการไหลของปั๊มหมุนเวียน
- แสดงกำลังไฟ (W) และพลังงานสะสมรายวัน (kWh) โดยประมาณ
- ตั้งตารางสลับแหล่งพลังงานและควบคุมเอง

## ข้อจำกัด

ค่าจากเซนเซอร์และคำสั่งอุปกรณ์เป็นข้อมูลจำลอง ยังไม่มีการเชื่อมต่อเซนเซอร์ มอเตอร์ ปั๊ม รีเลย์ หรือ Gateway จริง พลังงานเป็นตัวเลขประมาณเพื่อสาธิต ไม่มีฐานข้อมูลหรือ Supabase การหมุนเวียนน้ำช่วยกระจายคุณภาพน้ำ แต่ไม่ได้ปรับ pH โดยตรง

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลด `index.html` และ `README.md` ไว้ที่ระดับบนสุดของ repository
2. เปิด **Settings → Pages**
3. ใน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
5. รอ deployment เสร็จ ลิงก์เว็บจะเป็น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repository>/`

หน้าเว็บ GitHub Pages เป็นสาธารณะ อย่าใส่รหัสผ่านจริงหรือข้อมูลส่วนตัวลงใน repository
